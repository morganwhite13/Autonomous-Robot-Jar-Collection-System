# Webots robustness sweep

Generated by `tools/webots-sweep.sh`: each version ran on 6 shuffled worlds (seeds 1-6), with a 1500 s simulated-time limit. Each world places the five jars at random in the jar bay and nudges the robot's start pose by up to 8 cm and 6 degrees (`tools/WorldShuffle.java`). An observer counts a jar once it rests in the drop-off lane.

## How v2 got there

The same six worlds, run on v2 as it changed. Each column adds to the one before it ([BEFORE_AND_AFTER.md](BEFORE_AND_AFTER.md) has the details). The first Webots-ready v2, with only slower carry turns ([bug 11](BEFORE_AND_AFTER.md#11-full-speed-turns-threw-the-jar-out-of-the-gripper-found-in-webots)), delivered all five in 1 world of 6, and 22 of 30 jars while claiming 30; its run folders weren't kept, so it has no column.

- **carry low**: carries the jar 0.8 cm up instead of 5 cm, notices a jar that falls out, drives around whatever stalls it ([bugs 12, 13, 15](BEFORE_AND_AFTER.md#12-carrying-the-jar-5-cm-up-let-it-slip-out-found-in-webots))
- **jar map**: remembers where it saw jars, and approaches faster while a jar is far away ([speed-ups](BEFORE_AND_AFTER.md#16-speed-ups))
- **planned routes**: A*-planned carry and return routes
- **v2**: steers towards a far jar no third of the image clearly holds, and goes around whatever blocks an approach ([bug 14](BEFORE_AND_AFTER.md#14-a-small-far-jar-between-two-thirds-of-the-image-froze-the-approach-found-in-webots)). The sonar watch and grab check are on. Each was first tried alone on the jar-map version, on the same six worlds: the sonar watch never stopped for nothing and gave identical results, and the grab check never rejected a real grab (839 s median).
