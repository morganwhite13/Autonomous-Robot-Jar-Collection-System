# Before/after benchmark (kinematic model)

Generated by `tools/BeforeAfterBenchmark.java` (run `tools/run-tests.sh`). v1 numbers come from line-for-line ports of the original methods in `tests/LegacyV1.java`; v2 numbers run the real v2 classes. Both drive the same ideal differential-drive model (Pioneer 3-DX wheel radius 9.75 cm, track 33 cm, 32 ms steps). The model has no inertia, slip or box physics, so treat these as measurements of the control logic, not of the Webots simulation.

| Check | v1 (before) | v2 (after) |
|---|---|---|
| Turn-in-place: finishes within 1000 steps (6240 start/target pairs) | 91.8% (5726/6240) | 100.0% (6240/6240) |
| Turn-in-place: mean steps when it finishes | 16.7 | 22.9 |
| Turn-in-place: worst final heading error when it finishes | 3.0 deg | 3.0 deg |
| 360-degree jar scan: rotation actually covered | 271 deg | 371 deg |
| Scan finds a jar 1 m away, 45 deg right of the starting heading | no (blind spot) | yes |
| 530 cm leg starting 2.9 deg off: distance from waypoint at the end | 26.8 cm | 1.1 cm |
| Drive blocked by an immovable obstacle after 1 m | never returns (still pushing after 20,000 steps) | STALLED after 120 steps (3.8 s) |
| Longest straight approach before the time limit aborts it | 59 cm (300 steps) | 176 cm cap; aborts early only if not moving |
| Approach and grab a jar 1.5 m ahead in one attempt | no (needs about 641 steps) | yes |
| Route after a failed search for jars 2-5 | 41 m; first leg passes through 4 static obstacles (wooden box(1), wooden box(15), wooden box(12), wooden box(5)) | 0.8 m; stays at the search point |

Note: the whole v1 mission is not ported; only the methods measured above are. v1 and v2 share the same waypoints and gripper timings (checked by `RoutesTest`).
